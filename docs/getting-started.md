# Getting Started

## Что понадобится

| Компонент | Зачем нужен |
|-----------|-------------|
| Python 3 | Запуск бота |
| Telegram bot token | Подключение к Telegram Bot API |
| Ключ GigaChat или YandexGPT | Хотя бы один LLM-провайдер должен быть настроен |

## Установка

```bash
pip install -r requirements.txt
```

## Подготовка окружения

```bash
cp .env_example .env
```

После этого заполните `.env`. Подробная таблица переменных и готовые шаблоны лежат в `configuration.md`.

## Первый запуск

```bash
python -m bot.main
```

Если конфигурация корректна, бот начнет polling Telegram. Если обязательные переменные не заданы, приложение завершится с понятной ошибкой.

## Как проверить, что все работает

1. Откройте диалог с ботом в Telegram.
2. Отправьте `/start` и убедитесь, что бот показывает список команд.
3. Отправьте `/models`, чтобы увидеть доступные провайдеры.
4. Выберите модель командой `/model gigachat` или `/model yandex`.
5. Отправьте обычное текстовое сообщение и дождитесь ответа.

## Команды в Telegram

| Команда | Назначение |
|---------|------------|
| `/start` | Показать краткую справку |
| `/models` | Показать, какие модели настроены |
| `/model gigachat` | Переключиться на GigaChat |
| `/model yandex` | Переключиться на YandexGPT |

## Типовые проблемы

| Симптом | Что проверить |
|---------|---------------|
| `Не задан BOT_TOKEN.` | В `.env` отсутствует токен Telegram |
| Ошибка про отсутствие модели | Не настроен ни GigaChat, ни YandexGPT |
| Ответ не приходит от провайдера | Проверьте ключи и параметры API в `.env` |
